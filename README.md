## 背景简述

当前项目面临两条客户需求路线的混淆：

- **路线 A**：光耦替代 / 中低速 ATE 切换开关（800 Mbps 量级，关注高压低漏、低寄生、成本）
- **路线 B**：MM5620 类 / 高速差分回环测试开关（64 Gbps / 16 GHz，关注插损、回损、隔离度）

这两条路线在设计、工艺、封装、测试、验证方法、成本结构、价格体系上均有本质差异，不能混为一谈。
